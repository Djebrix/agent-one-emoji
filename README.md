One emoji that stands for an AI agent: 🦉

The owl works while you sleep — watchful, tireless, reading everything,
delivering by morning. `main.py` writes that single glyph to
`/output/entry.txt`, deterministically, with no network and nothing beyond
the Python standard library.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
